Landing page profissional para a [HTTP200.TI](https://http200.ti), consultoria especializada em tecnologia da informação.

## Sobre

Site estático (HTML, CSS, JavaScript puro) com design responsivo para todos os dispositivos, painel de administração e API serverless para gestão de conteúdo.

## Stack

- HTML5 semântico
- CSS3 com design system customizado
- JavaScript vanilla (sem dependências externas no frontend)
- API serverless Node.js (Vercel) com Supabase (PostgreSQL + Auth) e JWT

## Deploy

- **Site**: **GitHub Pages** (deploy automático via GitHub Actions no `main`)
- **API**: Vercel (funções serverless em `api/`)

🔗 **[Acesse o site](https://devleandrocoelho.github.io/http200-consultoria)**
